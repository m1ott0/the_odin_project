# Rock-Paper-Scissors

A simple rock-paper-scissors game, each round value is 1 point, round win value is +1, round loss value is -1, and round tie is +0 points, you can also enter a username if you want, and anytime during the game change him to whatever you want, and if want to reset the game points and results, just press the restart button.

## Technologies Used
- HTML5
- JavaScript
- CSS3
