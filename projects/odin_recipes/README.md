# Odin Recipes

My first project developed as part of The Odin Project curriculum.

A simple recipe website featuring a collection of selected recipes. The project was built to practice fundamental HTML concepts and create a basic multi-page website.

## Preview

[Live Demo](https://m1ott0.github.io/the_odin_project/projects/odin_recipes/)

## About

Odin Recipes is a beginner-level website that introduces visitors to a small collection of recipes.

The homepage welcomes visitors and provides links to three individual recipe pages:

- Omelete
- Misto Quente
- Crepioca

Each recipe has its own HTML page containing its corresponding information.

## Features

- Homepage with an introduction.
- Three individual recipe pages.
- Navigation between pages using links.
- Images displayed throughout the website.
- Basic CSS styling.

## Technologies Used

- HTML5
- CSS3

## Getting Started

### Prerequisites

- A modern web browser.
- Git (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/m1ott0/the_odin_project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd the_odin_project/projects/odin_recipes
   ```

3. Open `index.html` in your browser.
