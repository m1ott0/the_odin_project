# Astronomy Landing Page

My first landing page project developed as part of The Odin Project curriculum.

An astronomy-themed website created to practice CSS layouts, Flexbox, and the structure of a complete landing page.

## Preview

[Live Demo](https://m1ott0.github.io/the_odin_project/projects/landing_page/)

## About

The website is designed for people interested in astronomy and presents facts about the Solar System and the universe.

It features an introductory section, a collection of astronomy facts, a quotation from the Bible, and a registration section.

The project uses a video as part of its hero section and images to illustrate the astronomy facts.

## Features

- Astronomy-themed landing page.
- Navigation header.
- Hero section with background video.
- Collection of astronomy facts.
- Image-based content sections.
- Bible verse section.
- Registration call-to-action.
- Footer with author information.

## Technologies Used

- HTML5
- CSS3
- Flexbox

## Getting Started

### Prerequisites

- A modern web browser.
- Git (optional).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/m1ott0/the_odin_project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd the_odin_project/projects/landing_page
   ```

3. Open `index.html` in your browser.
