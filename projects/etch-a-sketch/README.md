## Getting Started

### Prerequisites

- A modern web browser
    
- Git (optional)
    

### Installation

1. Clone the repository:
    
    ```
    git clone 
    ```
    
2. Navigate to the project directory:
    
    ```
    cd etch-a-sketch
    ```
    
3. Open `index.html` in your browser.
