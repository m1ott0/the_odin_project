# Etch-A-Sketch

Eatch-a-Sketch is a toy that is played by paiting the squares in the grid until no ones left.

## Preview

[Live Demo](https://m1ott0.github.io/the_odin_project/projects/etch-a-sketch/)

  
## About

The game design is totally inspired in the classic etch-a-sketch released in July 12, 1960. And follow its original purpose to, unless the fact that in this case you play with a mouse.

## Features

- Custom Grid

- Reset Button

- Mouse Effects

- Sound Effects

- Classic Design
    

## Technologies Used

- HTML5
    
- CSS3
    
- JavaScript
    

## Usage

The game purpose is to paint all the squares, first, select a grid on the grid button, after that, the selected grid will appear on screen and then you can play with it.And if you want to reset and do it again, you can press the reset button and restart the game.

### Prerequisites

- A modern web browser
    
- Git (optional)
    

### Installation

1. Clone the repository:
    
    ```
    git clone https://github.com/m1ott0/the_odin_project
    ```
    
2. Navigate to the project directory:
    
    ```
    cd projects/etch-a-sketch
    ```
    
3. Open `index.html` in your browser.
