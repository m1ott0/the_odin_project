# The Odin Project — Full Stack Development

My personal repository for documenting my journey through [The Odin Project](https://www.theodinproject.com/) Full Stack JavaScript curriculum.

This repository contains exercises, assignments, and projects developed throughout my web development studies. It serves as a record of my progress, practical experience, and learning process.
